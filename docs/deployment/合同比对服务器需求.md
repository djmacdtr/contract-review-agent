# 合同比对 服务器需求

## 1. 部署方式

- 部署形式：Docker Compose
- 部署环境：内网 Linux 服务器
- 服务组件：FastAPI API、异步 Worker、PostgreSQL 16
- 外部依赖： LLM 网关、 OCR 服务、文件服务
- 本机不部署大模型或 OCR，不需要 GPU

## 2. 服务器配置

### 推荐配置

| 项目 | 要求 |
|---|---|
| CPU | 8 vCPU |
| 内存 | 16 GB |
| 磁盘 | 150 GB SSD，可扩容 |
| 系统 | 标准 Linux x86_64 |
| 网络 | 固定内网 IP |
| GPU | 不需要 |



## 3. 软件环境

| 项目 | 要求 |
|---|---|
| Docker Engine | 24 或以上版本 |
| Docker Compose | v2.20 或以上版本 |
| PostgreSQL | 16，默认由 Compose 部署 |
| 时区 | Asia/Shanghai |
| 时间同步 | 接入 NTP |

生产服务器无需单独安装 Python、Node.js、LLM 或 OCR 运行环境。

## 4. 网络要求

### 入站访问

| 来源 | 目标 | 端口 | 用途 |
|---|---|---:|---|
| 业务系统 | Agent 服务 | TCP 8000 | 内网 HTTP 调用业务接口 |
| API 网关/反向代理（可选） | FastAPI | TCP 8000 | 内部转发，按规范选择是否启用 HTTPS |
| 指定运维网络 | 服务器 | TCP 22 | SSH 运维，按规范开放 |

项目部署在受控内网时不强制使用 HTTPS，可直接通过内网 HTTP 调用 `8000` 端口。FastAPI 当前默认绑定宿主机 `127.0.0.1:8000`；如业务系统从其他服务器直接访问，部署时需改为绑定服务器内网地址或 `0.0.0.0:8000`，并通过防火墙限制允许访问的来源 IP。如已有统一 API 网关或 TLS 规范，可由网关负责 HTTPS 终止。

### 出站访问

以下地址必须从 **Worker 容器内部**连通：

| 目标 | 端口 | 用途 |
|---|---:|---|
| `10.50.11.18` | TCP 8080 | 集团 LLM 网关 |
| `10.50.11.17` | TCP 80 | 集团 OCR 服务 |
| 文件服务 | TCP 80/443 或实际端口 | 下载合同及辅助文件 |
| PostgreSQL | TCP 5432 | API、Worker 访问数据库，仅内部开放 |
| DNS | UDP/TCP 53 | 内部域名解析 |
| NTP | UDP 123 | 时间同步 |

网络侧还需满足：

- LLM、OCR、数据库和文件服务地址绕过互联网代理；
- 防火墙放行容器经宿主机实际出口 IP 发起的连接；
- 文件下载如发生重定向，重定向目标域名和端口也需放行；
- 验收以容器内连通结果为准，不能仅验证宿主机连通。
