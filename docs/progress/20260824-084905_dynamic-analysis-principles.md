## 重要决策

- 29 是当前样本和算法的偶然候选数量，不是稳定产品概念。
- 生产检查必须处理未知文档、未知字段和未知数值关系，不允许通过新增样本特例扩展能力。

- 常见字段种子和黄金样本可以提高召回和回归质量，但不能限制开放式输出。
