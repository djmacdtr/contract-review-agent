## 重要决策

- 本机 `.env` 的 OCR 地址、Key 和鉴权头有效，但 `OCR_ENABLED` 当前为 false；真实验收只对宿主机临时进程覆盖为 true，不覆盖用户 `.env`。
- Docker Desktop 到甲方 OCR 的既有空正文 502 仍按用户指示视为本机网络限制；本轮验收依据为宿主机 Worker 真实闭环。
- 同步 OCR Client 使用 `trust_env=False`，不加入宿主机代理、TLS 绕过或路由修改。
- `OCR_USED` 本身不强制人工复核；高置信相同扫描件可 `PASS`，结构不完整或部分页失败绝不生成 `PASS`。

## 已知问题与风险

- 甲方内网部署后仍必须从实际 Worker 容器补做至少 1 页真实扫描 PDF 验收；宿主机成功不能替代部署环境验证。
- 当前仅验证 1 页完全合成扫描件；未做 20/200 页、额度、低清、密码 PDF 和实际部分失败联调。
- OCR 是同步调用；大文档耗时和 Worker 心跳/甲方超时策略需在内网容量测试后再决定是否切换异步 API。
- 前端生产包有约 987 KB 主 chunk，当前测试控制台可用，但后续可按路由拆包。
- 当前自动浏览器不可用，尚缺一次人工或可连接浏览器的视觉交互验收。
- LangGraph 依赖仍有一个上游默认值弃用 warning，不影响本轮结果。
