## 已知问题与风险

- Docker Desktop 容器无法访问甲方 OCR 内网路径，表现为空正文 502；更像 Docker VM/零信任/路由问题。
- 服务根路径返回 HTTP 500，但正式 parser API 正常；不应使用根路径作为健康检查。
- OCR 会移除中文和数字之间的视觉空格，文本比对前必须继续使用统一归一化。
- 真实响应与 OpenAPI 存在字段偏差，自动生成客户端风险较高。
- 用户在对话中提供了 API Key；建议后续使用项目专用、可轮换的联调 Key。
- 尚未测试 20 页、200 页、旋转、低清晰度、部分失败、额度不足和字符级详情。
