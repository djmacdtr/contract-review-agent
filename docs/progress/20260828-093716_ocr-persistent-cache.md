# OCR 持久化缓存

## 本次目标

避免同一文件在任务重试、重新创建任务或 Worker 重启后重复调用甲方 OCR 服务。

## 已完成

- 新增基于文件 SHA-256 的持久化 OCR 解析结果缓存。
- 复用现有 `extraction_checkpoint` 表，不新增数据库迁移。
- 起草检查和放款比对统一接入缓存。
- 缓存命中后重新绑定当前任务的文件 ID、文件角色和文件名。
- 普通解析与印章图片解析使用不同缓存键，避免结果混用。
- OCR 地址、解析模式及相关解析参数发生变化时自动使用新的缓存项。
- 缓存读写异常只记录安全日志并回退到正常 OCR，不影响原业务流程。
- 并发写入使用 PostgreSQL upsert，避免重复缓存写入失败。
